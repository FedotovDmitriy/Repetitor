# Учебный контент

Приложение — один файл `index.html`. Ниже — где что лежит и как это менять. Для крупных правок удобно попросить Claude: он знает формат.

## Где что находится в `index.html`

| Блок | Как найти |
|---|---|
| Список тем и классов | `var TOPICS = {` — поля `grade`, `name`, `blurb`, `soon` (тема «готовится») |
| Классы | `var GRADES = [4,5,6,7,8,9]`, подписи `GRADE_LABEL`, `GRADE_SUB` |
| Тема (объяснение, примеры, задачи, тест, опыты) | `CONTENT.<id> = {` |
| Схемы SVG | `SVG_LIB.<ИМЯ> = function(){…}`; вставляются в объяснение маркером `__SVG_ИМЯ__` |
| Диагностики | `DIAGSETS[2]` … `DIAGSETS[8]` |
| Узлы диагностики → темы | `NODE_NAMES`, `NODE_TOPIC`, `NODE_ORDER`, `NODE_G4`, функция `topicForNode` |
| История версий | `var CHANGELOG = {…}` |

## Структура темы `CONTENT.<id>`

- `goal` — одно предложение: что ребёнок сможет после темы.
- `explain` — HTML, 600–900 слов: разделы `<h3>`, минимум один блок «Запомни» (`<div class="note">`) и один «Частая ошибка» (`<div class="warn">`), 2–3 схемы `<div class="figure">__SVG_NAME__</div>`.
- `examples` — не менее 6 разобранных примеров `{t:'условие', s:'решение'}`.
- `tasks` — ровно 20 задач `{q, ans, hint, sol}` по нарастающей сложности; не более 3 с выбором `{q, opts:[…], ans:<индекс>, hint, sol}`.
- `bonus` — задача со звёздочкой.
- `test` — ровно 8 заданий `{q, ans, sol}` (не более 2 с выбором).
- `lab` — не менее 4 «опытов из жизни» `{t, b}`.
- `videos` — необязательно.

Чтобы добавить тему: (1) создайте `CONTENT.<id> = {…}` рядом с другими; (2) добавьте строку в `TOPICS` с нужным `grade`; (3) при необходимости привяжите к узлу диагностики в `NODE_TOPIC`; (4) допишите пункт в `CHANGELOG`.

## Формат ответа

`ans` — **строка с одним числом**: `'42'`, `'-5'`, `'2.5'` (десятичная точка), `'3/4'`, смешанное `'1 3/4'`. Пробелы в больших числах приложение игнорирует само, но в `ans` пишите без пробелов (`'450000'`). Если нужна несократимая дробь — `reduced:true`. Запрещены ответы-слова, два числа, выражения. Единицы измерения указывайте в условии («в см»).

## Разметка текста

Дробь `{a|b}` (без вложенности; символ `|` больше нигде не использовать), смешанное `2{1|3}`, степень `x^2`, `10^3` (после `^` — буквы/цифры без скобок). Знаки: · − : ≤ ≥ ≠ ∈; единицы см², м² и т. п. Слово «Вычислите» не используется — оно непонятно детям: пишите «Найди значение выражения», «Реши», «Посчитай», «Найди».

## Схемы

Каждая схема — функция, возвращающая строку `<svg …>`. Правила: цвета только через `var(--…)` (светлая и тёмная тема), `viewBox`, `max-width` 300–560 px, шрифт не меньше 13, читаемость на ширине 340 px, числа в подписях верны. Схема должна объяснять идею, а не украшать.

## Диагностика

Ребёнок класса N проходит наборы за классы N−2 и N−1 (по 8 заданий, всего 16). Каждое задание: `{node, q, ans, sol}` (и `reduced` при необходимости). `node` — «узел знаний»; по нему результат превращается в рекомендацию темы. Требования: внутри набора узлы не повторяются; задания разных классов **не повторяют друг друга по смыслу** (не «те же дроби»), поэтому при добавлении задания сверяйтесь с соседними наборами.

Узлы младших классов (`b_*`) для 4 класса ведут на темы 4 класса (`NODE_G4`), для остальных — на темы 5 класса.

## Проверка перед публикацией

1. Все числовые ответы пересчитаны независимо (скриптом), а не только «на глаз».
2. Открыть тему на телефоне (ширина 340–380 px) и в тёмной теме: нет наложений и горизонтальной прокрутки.
3. Пройти тест и диагностику от начала до конца хотя бы для одного профиля.
4. Убедиться, что в консоли браузера нет ошибок.

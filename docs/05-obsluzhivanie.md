# Обслуживание

## Выпуск новой версии

1. **Правки.** Измените `index.html` (тема, задача, схема, интерфейс) — см. [контент](04-kontent.md).
2. **Дневник версий.** Обязательно:
   - в `index.html` в блоке `var CHANGELOG` поднимите `current`, добавьте запись вверху `versions` (номер, дата, заголовок, список изменений) и обновите блок `next` — что ожидается в следующей версии;
   - продублируйте запись в `CHANGELOG.md`.
   Нумерация: **2.1.0 → 2.1.1** — исправления; **2.1.0 → 2.2.0** — новые темы и функции; **2.x → 3.0.0** — крупное переосмысление.
3. **Проверка.** Откройте сайт локально (файл `index.html` открывается двойным щелчком), пройдите диагностику и один тест, посмотрите телефонную ширину и тёмную тему.
4. **Публикация.** `git add . && git commit -m "Версия 2.1.0: …" && git push`. Cloudflare опубликует за 1–2 минуты. Проверьте страницу «Версии» на сайте: номер должен совпасть.
5. Если что-то сломалось — в Cloudflare Pages → **Deployments** откройте предыдущую публикацию → **Rollback to this deployment**.

## Резервные копии

Данные семей лежат в D1.

- Экспорт: `wrangler d1 export mvk-db --remote --output=backup.sql` (нужен установленный wrangler) — делайте раз в месяц и перед крупными изменениями схемы.
- Восстановление: D1 хранит историю изменений (Time Travel) — восстановление на момент в прошлом доступно в панели базы.
- Прогресс также дублируется в `localStorage` устройства, где занимался ребёнок.

## Обновление схемы базы

Новые таблицы и колонки добавляйте в `db/schema.sql` и выполняйте нужные команды в консоли D1 вручную (`ALTER TABLE …`). Команды в файле написаны через `IF NOT EXISTS`, поэтому повторный запуск безопасен.

## Ротация секретов

Сменить `ADMIN_PASSWORD`, `GOOGLE_CLIENT_SECRET`, `RESEND_API_KEY`: обновите значение в **Settings → Variables and Secrets** и сделайте новую публикацию (Retry deployment). Смена `SESSION_SECRET` выйдет из аккаунтов всех пользователей — они просто войдут заново.

## Что смотреть регулярно

- `/admin/` — новые обращения и запросы PIN (письма могут попасть в спам).
- Panel Cloudflare → D1 → Metrics — объём базы и число запросов (бесплатных лимитов семье хватает с большим запасом).
- Resend → Emails — доставка писем.

## Устранение неполадок

| Симптом | Что проверить |
|---|---|
| На сайте видна страница «Загрузка…» и ничего не происходит | Ответ `/api/me` очень долгий; обновите страницу; проверьте статус Cloudflare |
| Страница входа не появляется, приложение работает «по-старому» | Не создана привязка D1 `DB` или нет новой публикации — откройте `/api/me` |
| Ребёнок не может войти со своей почтой | Родитель не вписал Gmail в «Кабинете родителя → Вход детей через Gmail», либо адрес — владелец другой семьи |
| Прогресс на телефоне и компьютере разный | Устройства вошли под разными семьями, либо на одном из них нет интернета; подождите 10–15 секунд после действия |
| Письмо поддержки не пришло | Смотрите админ-панель: обращение там есть даже без письма; проверьте `RESEND_API_KEY` |
| Забыл мастер-пароль админки | Задайте новое значение `ADMIN_PASSWORD` и сделайте новую публикацию |
| Родитель забыл пароль кабинета и нет доступа к Gmail | Пароль виден в `/admin/` рядом с семьёй |

## Приватность

Приложение хранит: Gmail родителя и детей (если указаны), имена детей, класс, PIN, пароль кабинета, результаты обучения и тексты обращений в поддержку. Данные лежат в вашей базе D1 в вашем аккаунте Cloudflare; сторонним лицам не передаются. Google получает только факт входа в приложение; Resend — тексты писем поддержки. Чтобы удалить семью, удалите строки из `families`, `docs`, `kid_emails` и `support` по её `family_id`.

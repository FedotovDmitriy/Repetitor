# Математика в клетку — автономная версия

Это самостоятельная версия приложения (файл `index.html`), которая работает без аккаунта claude.ai. Прогресс хранится в браузере устройства (localStorage) — на каждом устройстве отдельно, синхронизации между телефоном и компьютером в этой версии нет (её можно добавить позже, см. раздел «Синхронизация между устройствами» ниже).

## Шаг 1. Создать репозиторий на GitHub

1. Зайдите на [github.com](https://github.com) и нажмите **New repository**.
2. Дайте имя, например `matematika-v-kletku`. Можно сделать репозиторий приватным — на публикацию сайта это не влияет.
3. Не добавляйте README/gitignore при создании — они не нужны, у нас уже всё есть.

## Шаг 2. Загрузить файл

Самый простой способ — через веб-интерфейс GitHub:

1. Откройте созданный репозиторий → **Add file → Upload files**.
2. Перетащите туда файл `index.html` из этой папки.
3. Нажмите **Commit changes**.

(Если пользуетесь git через терминал: `git init && git add index.html && git commit -m "init" && git remote add origin <ссылка на репозиторий> && git push -u origin main`.)

## Шаг 3. Подключить Cloudflare Pages

1. Зайдите на [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Pages → Connect to Git**.
2. Выберите репозиторий, который вы только что создали.
3. В настройках сборки ничего менять не нужно — framework preset оставьте **None**, build command оставьте пустым, output directory укажите `/` (корень).
4. Нажмите **Save and Deploy**.

Через минуту-две Cloudflare выдаст адрес вида `matematika-v-kletku.pages.dev` — это и есть готовый сайт, доступный с любого устройства и без входа в claude.ai.

## Шаг 4. Проверить

Откройте выданный адрес на телефоне и на компьютере — приложение должно полностью работать: создание профилей, диагностика, темы, тесты. Прогресс на телефоне и на компьютере будет храниться отдельно (см. ниже про синхронизацию).

## Шаг 5. Обновления в будущем

Когда понадобится обновить контент — попросите Claude собрать новую версию `index.html` (в чате или в новой сессии, сославшись на этот проект), затем повторите шаг 2 (загрузите новый файл поверх старого, GitHub сам создаст новый коммит) — Cloudflare Pages передеплоит сайт автоматически при каждом пуше в репозиторий.

## Синхронизация между устройствами (опционально)

Сейчас прогресс хранится в localStorage браузера — то есть если ребёнок занимается и на телефоне, и на компьютере, это будут два независимых набора прогресса. Если это важно, есть два пути:

**Простой:** договориться заниматься с одного устройства (например, всегда с ноутбука).

**Технический:** добавить Cloudflare Worker + KV (или D1), который будет хранить прогресс на сервере вместо localStorage. Это требует:
- создать KV-неймспейс или D1-базу в Cloudflare;
- написать Pages Function (`/functions/api/progress.js`), которая читает/пишет прогресс по ключу профиля;
- заменить в `index.html` вызовы `localStorage` на `fetch('/api/progress', ...)`.

Это отдельная задача на 1–2 часа работы. Если понадобится — попросите Claude написать этот слой отдельно, приложив ссылку на уже задеплоенный сайт.

## Что внутри

Один файл `index.html` — HTML, CSS и JavaScript, без сборки, без npm, без зависимостей (кроме шрифта Google Fonts, который подключается по ссылке). Открывается напрямую в браузере или на любом статическом хостинге (GitHub Pages, Netlify, Vercel, Cloudflare Pages — не только Cloudflare).

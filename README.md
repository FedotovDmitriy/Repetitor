# Математика в клетку

Обучающий сайт по математике для школьника 4–9 классов с пробелами в знаниях (программа ФГОС, русский язык). Ребёнок проходит входную диагностику, получает карту тем, учится по объяснениям со схемами, решает задачи с подсказками, делает «опыты из жизни» и сдаёт тесты. Родитель видит результаты и ошибки в своём кабинете.

**Адрес сайта:** https://repetitor-5oz.pages.dev  ·  **Текущая версия:** см. [CHANGELOG.md](CHANGELOG.md)

## Что внутри

| Что | Где |
|---|---|
| Всё приложение (страницы, темы, схемы, проверка ответов) | `index.html` — один файл, без сборки |
| Сервер: вход через Gmail, синхронизация, поддержка, админка | `functions/api/[[route]].js` |
| Админ-панель (скрытая, по мастер-паролю) | `admin/index.html` → адрес `/admin/` |
| Схема базы данных D1 | `db/schema.sql` |
| Скачиваемые книги (справочник + сборник задач в PDF) для 5 и 7 класса | `books/` |
| Заголовки и запрет индексации | `_headers`, `robots.txt` |
| История версий (дневник изменений) | `CHANGELOG.md` и страница «Версии» в самом приложении |

Сайт **работает и без сервера**: если сервер не подключён, прогресс хранится в браузере устройства, а кнопка поддержки открывает почтовую программу. Сервер (вход через Gmail, общий прогресс на всех устройствах, письма, админ-панель) включается настройкой Cloudflare, Google и Resend — [пошаговая инструкция](docs/02-ustanovka.md).

## Быстрый старт (только сайт, без сервера)

1. Загрузите содержимое этой папки в репозиторий GitHub.
2. В Cloudflare: Workers & Pages → Create → Pages → Connect to Git → выберите репозиторий → Save and Deploy (framework — None, build command — пусто, output directory — `/`).
3. Каждый `git push` в ветку `main` публикует новую версию автоматически.
